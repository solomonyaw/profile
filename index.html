MSc Academic Curriculum

Building the Knowledge to Engineer Modern Networks

My MSc in Networking and Telecommunication Systems is intended to help me develop a deeper understanding of how communication networks are designed, deployed, managed, secured, and optimized. The 8 subject areas below represent the technical foundation I aim to build throughout my academic journey.

Computer Networking, Protocols & Architecture

Network Protocols Advanced Switching Network Design & Analysis Wide Area Networks Data Center Technologies Network Operations

These subjects will help me master network architecture, hierarchical addressing, routing protocols, switching, segmentation, traffic flow, performance monitoring, troubleshooting, and designing resilient networks connecting offices, data centers, and distributed systems.

Target Career Roles: Network Engineer, Network Support Engineer, Network Operations Engineer, Data Center Network Engineer.

Telecommunications & Communication Systems

Wireless & Mobile Systems Digital Communications Optical & Satellite Systems Telecom Technologies Policy & Operating Environment

These subjects will help me understand how digital information travels through communication media, how wireless and 5G cellular technologies support mobile connectivity, and how optical fiber backbones and satellite systems form national and international communication infrastructure.

Target Career Roles: Telecommunications Engineer, Radio Access Network (RAN) Engineer, Transmission Engineer, Network Planning Engineer.

Network Security & Infrastructure Resilience

Systems & Network Security Secure Architecture Monitoring & Threat Awareness Risk Reduction Resilient Infrastructure

Secure communication networks require a rigorous understanding of threat models, security hardening, access control lists, packet filtering, continuous telemetry, and resilient failover topologies to protect data integrity and service availability.

Target Career Roles: Network Security Engineer, Security Operations Analyst, Network Infrastructure Security Specialist (subject to practical certifications).

Cloud, Software-Defined Networking & Virtualization

SDN Architecture Cloud Systems Data Center Networking Network Virtualization Programmable Infrastructure

Exploring how cloud architectures, virtualization, and software-defined network controllers (SDN) decouple the control plane from forwarding hardware, revolutionizing how enterprise networks are provisioned, scaled, managed, and orchestrated.

Target Career Roles: Cloud Network Engineer, Network Automation Engineer, Infrastructure Engineer.

Artificial Intelligence & Intelligent Networks

AI for Communication Intelligent Monitoring Data-Driven Optimization Predictive Fault Detection Traffic Pattern Analytics

Investigating how machine learning can analyze high-throughput network telemetry, identify malicious traffic anomalies, automate quality-of-service optimization, and enable predictive fault isolation in complex modern networks.

Target Career Roles: Network Automation Engineer, AI-Assisted Network Operations Specialist, Network Analytics Professional.

IoT & Distributed Communication Systems

IoT Smart Systems Wireless Sensor Networks Ad Hoc Networks Distributed Computing Network Programming

Understanding how constrained devices, wireless sensor grids, distributed nodes, and specialized IoT communication protocols interconnect to power smart cities, industrial monitoring, environmental sensing, and modern telemetry systems.

Target Career Roles: IoT Network Engineer, Network Systems Developer, Connected Infrastructure Specialist.

Research, Signal Processing & Innovation

Research Methods Digital Signal Processing Academic Seminars Evidence Evaluation Scientific Inquiry

Developing rigorous scientific research methodologies, signal transformation concepts, mathematical analysis of communication waveforms, and presentation skills to systematically investigate complex networking and telecommunication problems.

Target Career Roles: Technical Researcher, Network Planning Analyst, Telecommunications Systems Specialist.

Professional Practice, Management & Ethics

Ethics in Communication Network Management Technology Entrepreneurship Project Planning Professional Seminars

Understanding professional engineering ethics, regulatory frameworks, commercial network operations, budgeting, and project execution principles that complement pure technical engineering in real-world deployment.
